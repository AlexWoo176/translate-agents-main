# Check Project Status Prompt

Hãy kiểm tra trạng thái hiện tại của sách.

## Thông tin

- Mã sách: [bookSlug, ví dụ: psychology-2e]

## Yêu cầu

1. Cho biết sách đang ở phase nào trong workflow.
2. Liệt kê các phase đã hoàn thành.
3. Liệt kê các phase còn lỗi hoặc chưa chạy.
4. Báo cáo trạng thái các quality gate:
   - Gate nào đang **pass** ✅
   - Gate nào đang **warning** ⚠️
   - Gate nào đang **failed** ❌
   - Gate nào cần **human review** 👤
5. Cho biết glossary đang ở trạng thái nào (approved bao nhiêu %, còn pending bao nhiêu).
6. Đề xuất bước tiếp theo an toàn nhất.
7. Giải thích kết quả bằng ngôn ngữ dễ hiểu — không dùng thuật ngữ kỹ thuật không cần thiết.
