# Book Project Structure

Each book translation project is isolated in its own directory under `books/{bookSlug}/`.

## Directory Skeleton

```text
books/{bookSlug}/
├── book.config.json                  # Book-specific metadata configuration
├── project-plan.json                 # Auto-generated phase plan
├── project-plan.md                   # Human-readable phase plan
├── tasks.md                          # Chapter-by-chapter task checklist
├── workflow-checkpoint.json          # Keeps progress of the orchestrator runs
├── workflow-state.json               # Aggregates overall project & gate status
├── glossary.csv                      # Main bilingual term mappings
├── glossary-candidates.csv           # Suggested terms generated by core
├── glossary-candidates.json          # Suggested terms in structured JSON
├── glossary-review/                  # Review spreadsheet outputs and results
│   ├── glossary-review-sheet.csv     # Exported sheet for expert review
│   └── glossary-review-instructions.md # Instructions for experts
├── glossary/
│   ├── versions/                     # Historical backup files
│   ├── glossary-change-log.md        # Change log in markdown
│   └── glossary-change-log.json      # Change log in JSON
├── assets/                           # Shared media assets (images, CSS)
├── preview/
│   └── html/                         # Built bilingual preview pages
├── exports/
│   └── epub/                         # Final compiled book.epub
├── reports/
│   ├── workflow-runs/                # Orchestrator runs logs & JSON/MD reports
│   └── *.md/*.json                   # Individual quality gate validation reports
├── backups/                          # Safe state backups
└── chapters/                         # Chapter outputs
    ├── chapter-1/
    │   ├── 01-raw/                   # Downloaded raw OpenStax source HTML
    │   ├── 02-clean/                 # Normalized structure HTML files
    │   ├── 03-analyzed/              # Terminology & structural analyses
    │   ├── 04-prep/                  # Translation-ready bilingual HTML
    │   ├── 05-translated/            # Final bilingual translated HTML files
    │   ├── 05-translated-draft/      # Translation draft outputs
    │   ├── 06-reviews/               # Semantic checks & QA feedback md files
    │   └── 07-archive/               # VN-only compiled clean output
    ├── chapter-2/
    ...
```

## Description of Phase Folders

- **`01-raw`**: The untouched HTML crawled from the OpenStax website.
- **`02-clean`**: Cleaned and validated HTML with OpenStax widgets normalized, keeping academic markup.
- **`03-analyzed`**: Contains term extractions, structure maps, and metadata contexts used by translators.
- **`04-prep`**: Templates split into `eng hidden` structures and bilingual tags.
- **`05-translated`**: The final bilingual translation output containing `vn visible` segments.
- **`05-translated-draft`** / **`.draft.html`**: Temporary translation drafts before confirmation or approval.
- **`06-reviews`**: Human/AI feedback logs and edits check-tables.
- **`07-archive`**: Monolingual (Vietnamese) clean output ready for preview bundling.
